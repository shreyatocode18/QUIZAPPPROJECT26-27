This is a simple, beginner-friendly quiz application built entirely in Python. 
It was originally created as a learning exercise, and I've customized it as my own by adding my own set of questions, 
tweaking the structure, and making it my own. The app presents a series of multiple-choice questions, 
checks your answers, tracks your score, and gives you friendly feedback at the end.
It's a great starting point for anyone learning Python — it demonstrates
dictionaries,
lists,
loops, 
functions, 
and basic input handling all in one small project.
Feel free to explore the code, modify the questions, and make it yours too!
