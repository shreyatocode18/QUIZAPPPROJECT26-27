# 🎯 Interactive Quiz Application Using Python

A Python-based **Interactive Quiz Application** developed using **Tkinter** for the graphical user interface and the **Open Trivia Database (OpenTDB) API** for fetching quiz questions dynamically. The application presents True/False questions, evaluates user responses, updates the score in real time, and provides visual feedback.

---

## 📖 Project Overview

The Interactive Quiz Application is an educational desktop application designed to test users' knowledge through an engaging quiz experience. Questions are retrieved dynamically from the Open Trivia Database (OpenTDB), ensuring a different set of questions each time the application runs.

The project demonstrates the practical implementation of:

- Object-Oriented Programming (OOP)
- Modular Programming
- API Integration
- GUI Development using Tkinter
- JSON Data Handling

---

## ✨ Features

- 🎯 Interactive graphical user interface (GUI)
- 🌐 Dynamic quiz questions fetched from OpenTDB API
- ✅ True/False answer selection
- 📊 Live score tracking
- 🟢 Visual feedback for correct answers
- 🔴 Visual feedback for incorrect answers
- 🔄 Automatic loading of the next question
- 🏁 Quiz completion message

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/Interactive-Quiz-Application.git
```

### 2. Navigate to the project folder

```bash
cd Interactive-Quiz-Application
```

### 3. Install the required package

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python main.py
```
